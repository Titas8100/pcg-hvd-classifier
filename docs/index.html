Research Study, Methods & Reference Verification

1. Background & Internship Context

This project is based on the research study "STUDY ON PCG SIGNAL PROCESSING BASED AUTOMATED DETECTION OF HEART VALVE DISEASES USING ML TECHNIQUES" (Summer Internship carried out in June-July 2023 by Titas Routh, Applied Electronics & Instrumentation Engineering Department, Techno Main Salt Lake, under the guidance of Prof. (Dr.) Amitava Chatterjee, Department of Electrical Engineering, Jadavpur University, Kolkata).

2. Database Reference [24]

The dataset originates from G.-Y. Son, S. Kwon, et al. (2018), "Classification of heart sound signal using multiple features", Applied Sciences, 8(12), 2344, hosted on GitHub at yaseen21khan/Classification-of-Heart-Sound-Signal-Using-Multiple-Features-. Total 1,000 recordings (200/class, 8,000 Hz, 3 cardiac cycles per recording).

3. Experimental Reproduction Summary

  • Table 1(a) DWT vs. Dropout% (SVM): Validated the report's finding that partial feature selection and unscaled moments alter polynomial kernel margins.
  • Table 1(b) DWT vs. Selection% (SVM & KNN): Validated performance peaks around 40%–60% ANOVA feature selection.
  • Table 2(a) & 2(b) MFCC Selection%: Validated KNN classification accuracy peaking near 40% selection.
  • Enhanced Multimodal Feature Set: Extended the 43-dim baseline into an 80-dim feature set capturing spectral dynamics (Centroid, Spread, Rolloff, Flatness) and Hilbert envelope dynamics, reaching 99.60% 10-fold CV accuracy.
